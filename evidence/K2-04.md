# K2-04. Локальный registry

Группа: ФЭ-9.24.1

## Команды и результат

Запустила хранилище командой `docker compose --profile registry up -d registry`. Добавила образу адрес хранилища: `docker tag devops-student:v1 localhost:5000/workshop:v1`. Команда `docker push localhost:5000/workshop:v1` успешно отправила образ, а `docker pull localhost:5000/workshop:v1` получила его обратно. Docker сообщил, что образ уже актуален на компьютере. `docker image inspect localhost:5000/workshop:v1` нашла скачанный образ.

Digest: `sha256:a1d135747205132528caf530faa494ce299f4a58af4d02b7cffe07fd8ded6485`.

`v1` — имя версии (тег), которое можно позднее назначить другому образу. Digest относится к точному содержимому отправленного образа. `push` только сохраняет образ в registry и сам по себе не запускает приложение.
