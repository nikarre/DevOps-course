# K2-04. Registry

Группа: ФЭ-9.24.1

Запустила локальный registry командой `docker compose --profile registry up -d registry`. Затем выполнила `docker tag devops-student:v1 localhost:5000/workshop:v1`, `docker push localhost:5000/workshop:v1` и `docker pull localhost:5000/workshop:v1`. Отправка прошла успешно. При скачивании Docker сообщил, что такой образ уже есть на компьютере. Команда `docker image inspect localhost:5000/workshop:v1` нашла его.

Digest отправленного образа: `sha256:f5cff6271cd9f73b59d93ca40251af02159a9277ec3733ab8bc0005a811fca53`.

`v1` — это название версии, его можно перенести на другой образ. Digest указывает на конкретный отправленный образ. `docker push` только сохраняет образ в registry, приложение от этого не запускается.

Использовала задание `practicals/KT2.md` и помощь чатгпт.
