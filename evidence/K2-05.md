# K2-05. Ошибка конфигурации

Группа: ФЭ-9.24.1

## Что произошло

В `compose.student.yaml` временно заменила адрес API у `web` на `http://api:9999` и применила настройку командой `docker compose -f compose.student.yaml up -d web`. Список заявок перестал открываться: запрос `/api/requests` вернул ошибку **503** и `upstream_unavailable`. В логах `web` было `target: "http://api:9999"` и `Connection refused`.

Порт 9999 ошибочный: `api` слушает порт **8000** внутри сети Compose. При этом контейнер `web` оставался `healthy`, потому что проверка `/health` подтверждает работу самого процесса, а не связь с API.

Вернула `API_URL: http://api:8000`, снова выполнила `docker compose -f compose.student.yaml up -d web`. Список заявок ответил **200** и показал прежние заявки. После исправления через страницу отправила новую заявку **№8** («Не работает экран»). Страница показала «Заявка №8 принята» и добавила её в список. Значит, связь `web` с `api` восстановлена.
