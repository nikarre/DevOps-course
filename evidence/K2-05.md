# K2-05. Ошибка в настройке

Группа: ФЭ-9.24.1

Временно поставила для `web` адрес `API_URL: http://api:9999` и применила изменение командой `docker compose -f compose.student.yaml up -d web`. Список заявок перестал загружаться: запрос вернул ошибку 503 (`upstream_unavailable`). В логах `web` было `target: "http://api:9999"` и `Connection refused`.

Причина — неверный порт. `api` работает на порту 8000, а на 9999 никто не отвечает. Сам контейнер `web` при этом оставался `healthy`: проверка `/health` не проверяет его связь с `api`.

Вернула `API_URL: http://api:8000` и снова выполнила `docker compose -f compose.student.yaml up -d web`. Список заявок загрузился. Через страницу отправила заявку №8 «Не работает экран»: появилось сообщение «Заявка №8 принята», и запись добавилась в список.

Использовала задание `practicals/KT2.md` и помощь ChatGPT.
