# K2-02. Свой Dockerfile

Группа: ФЭ-9.24.1

## Что я сделала

Создала `lab/Dockerfile` и собрала образ командой `docker build -f lab/Dockerfile -t devops-student:v1 lab`. Сборка прошла успешно. Команда `docker image inspect devops-student:v1` показала пользователя `10001:10001` и метку `course.student=04092008`.

Затем запустила `docker run --rm -d --name student-web -p 127.0.0.1:8081:8000 -e ROLE=web devops-student:v1`. Адрес `http://localhost:8081/health` ответил `{"process": "running", "role": "web"}`. В `docker logs student-web` видно, что приложение запустилось и ответило на `/health` с кодом 200. После проверки остановила контейнер командой `docker stop student-web`.

## Что означают настройки

`COPY` кладёт файлы приложения в образ, а `CMD` запускает `app.py`. `USER 10001:10001` запускает приложение без прав администратора. Папка `/data` заранее создана и доступна этому пользователю для записи. `EXPOSE 8000` показывает, какой порт использует приложение внутри контейнера; для доступа из браузера дополнительно нужен `-p`, который связывает его с портом 8081 на MacBook.
