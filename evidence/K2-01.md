# K2-01. Образ и контейнер

Группа: ФЭ-9.24.1

## Команды и результаты

1. `docker image inspect devops-course:base` — найден образ `devops-course:base` для `linux/arm64`, ID `sha256:936f85afe92f11a74e29fb6e66e22bd92016a5abfa575a0e65abb6f1ce8ad465`.
2. `docker compose ps` — из этого образа запущены два контейнера: `devops-course-api-1` (принимает и хранит заявки) и `devops-course-web-1` (показывает страницу). Оба были `healthy`.
3. `docker compose stop web` — `api` остался `healthy`, а подключение к `localhost:8080` завершилось ошибкой `Failed to connect`.
4. `docker compose start web` — оба сервиса снова стали `healthy`. Адрес `/health` ответил `{"process": "running", "role": "web"}`.
5. На странице `localhost:8080` отправлена учебная заявка «Не работает экран». Появилось подтверждение «Заявка №1 принята», а в списке — запись `#1 · Не работает экран`.

## Вывод

Образ - основа для двух контейнеров с разными ролями. При остановке `web` страница стала недоступна, хотя `api` продолжал работать. После запуска `web` отправка заявки снова работала. **Образ при остановке контейнера не удаляется.**
