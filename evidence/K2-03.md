# K2-03. Compose и сохранность заявок

Группа: ФЭ-9.24.1

В `compose.student.yaml` для `web` и `api` указан мой образ `devops-student:v1`. После `docker compose stop` проверила файл командой `docker compose -f compose.student.yaml config` и запустила приложение: `docker compose -f compose.student.yaml up -d`. Оба контейнера заработали.

Через страницу отправила заявку №5 «Не заряжается». Потом пересоздала `api` командой `docker compose -f compose.student.yaml up -d --no-deps --force-recreate api`. Заявка №5 осталась в списке. После этого отправила заявку №6 «Не запускается программа» — она тоже появилась.

`web` обращается к `api` по адресу `http://api:8000`: это имя и порт сервиса внутри Docker. На MacBook страница открывается через `localhost:8080`; этот порт ведёт к порту 8000 контейнера `web`. Заявки лежат в томе `requests`, поэтому при замене контейнера они не пропали. Без отдельного тома база внутри старого контейнера была бы потеряна.

Чтобы снова открыть приложение: в папке проекта выполнить `docker compose -f compose.student.yaml up -d`, затем перейти на `http://localhost:8080`.
